# Инбокс задач (_TODO_)

Сюда кладутся заметки, замечания и задачи от внешних ИИ или самого пользователя.
Агент при старте сессии:

1. просматривает каждый файл в `_TODO_/`;
2. превращает содержимое в пункт(ы) `ROADMAP.md` (с дедупликацией, этапом и приоритетом);
3. переносит отработанный файл в `_TODO_/done/` (допустимо приложить `DONE`-пометку).

Формат входного файла свободный; приветствуется минимум:

```
# Заголовок задачи
Приоритет: высокий/средний/низкий (опционально)
Этап: (опционально)

Описание проблемы/идеи, файлы, ссылки.
```
