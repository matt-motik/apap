## Что уже решено (не пересматривать)

- Один щелчок = 2 % громкости; «вверх» — громче с учётом системной инверсии (решение 3, НФ-2).

- macOS до замера — по API платформы: признак точных дельт, системная инверсия, инерция игнорируется (ТЗ-36).
- Исходы восьми пар «платформа (GNOME, KDE, Windows, macOS) × источник (над ползунком, над треем)»: подтверждено экспериментом / по документации платформы / правило по умолчанию / источника нет. «Источника нет» — не дефект; глобальный перехват мыши в объём не входит (ТЗ-36).
- Если слой Slint не передаёт тип дельты или фазу, модуль ввода получает события ниже Slint; способ — Часть 3 (ТЗ-36).
