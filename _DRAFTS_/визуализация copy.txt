# ТЗ: Визуализация аудио в плеере APAP (Rust + Slint)
**Версия:** 4.0 (Актуализировано под apap.git)
**Дата:** 2024


---

## 1. Общие положения

### 1.1. Назначение
Добавить в музыкальный плеер **APAP** подсистему визуализации с тремя режимами, независимыми настройками для каждого и поддержкой стерео/моно. Интеграция должна быть выполнена с учетом текущей архитектуры приложения (модули `audio`, `ui`, `settings`).

### 1.2. Область применения
- **Крейт/модуль:** `audio::visualizer` (обработка сигнала), `ui::visualizer` (Slint-компоненты).
- **Интеграция:**
  - `audio::player` (PlaybackCore, cpal callback).
  - `audio::decoder` (`Decoder`, `DsdDecoder`).
  - `settings` (сериализация в TOML).
- **UI:** Отдельная вкладка в настройках, компонент отображения в главном окне.
- **Хранение:** Конфиг в `~/.config/apap/config.toml`, кэш в `~/.cache/apap/viz/`.

### 1.3. Термины
| Термин | Значение |
|---|---|
| **Полнотрековая визуализация** | Строится один раз по всему треку, кэшируется, поверх движется курсор позиции. |
| **Мгновенная визуализация** | Обновляется непрерывно во время воспроизведения (Real-time). |
| **Tap** | Копия PCM-потока, ответвляемая до записи в устройство вывода (без модификации оригинала). |
| **Bit-perfect** | Режим вывода без ресемплинга и софтверной громкости внутри приложения. Громкость регулируется внешним предусилителем/ОС. |
| **Native DSD / DoP** | Режимы вывода, при которых визуализация недоступна (отсутствует PCM-поток для анализа). |

## 2. Архитектура

### 2.1. Классы визуализаций

| Класс | Режимы | Источник данных | Частота обновления |
|---|---|---|---|
| **Полнотрековый** | Осциллограмма, Спектрограмма | Файл через `Decoder`/`DsdDecoder` (параллельно плееру) | Один раз при загрузке трека |
| **Мгновенный** | Анализатор спектра | Ring buffer (tap из audio callback) | 30–60 FPS (по таймеру UI) |
| **Отключено** | Плейсхолдер | — | — |

### 2.2. Компоненты системы

```text
                            ┌────────────────────────┐
                            │      UI (Slint)        │
                            │  - VisualizerComponent │
                            │  - SettingsTab         │
                            └────┬──────────────▲────┘
                                 │ команды      │ данные (image/model)
                                 ▼              │
        ┌──────────────────────────────┐  ┌──────────────────┐
        │  FullTrackWorker             │  │  LiveWorker      │
        │  (Background Thread)         │  │  (Background Thread)
        │  - Чтение файла              │  │  - FFT (rustfft) │
        │  - Построение изображения    │  │  - Сглаживание   │
        │  - Кэш (RAM/Disk)            │  │  - Модель полос  │
        └────────────┬─────────────────┘  └────────▲─────────┘
                     │                              │
                     ▼                              │
              Кэш изображений              Ring Buffer (rtrb)
              (LRU + Disk)                 ┌──────────────────┐
                                           │  PlaybackCore    │
                                           │  (cpal callback) │
                                           └──────────────────┘
```

### 2.3. Поток данных

**Полнотрековая (Осциллограмма/Спектрограмма):**
1. Событие `TrackChanged` → UI запрашивает построение.
2. `FullTrackWorker` открывает файл независимо от основного плеера.
3. Чтение блоками, расчет данных (min/max для осциллограммы, FFT для спектра).
4. Генерация `SharedPixelBuffer` (изображение).
5. Отправка в UI, сохранение в кэш.
6. UI рисует изображение + вертикальную линию курса (координата берется из текущего прогресса плеера, аналогично seek-bar).

**Мгновенная (Спектр):**
1. Audio callback пишет копию PCM в lock-free ring buffer (`rtrb`) только если режим активен.
2. `LiveWorker` читает буфер, делает FFT, применяет сглаживание (decay/peak hold).
3. Данные передаются в UI через `ModelRc<[float]>`.
4. UI отрисовывает столбцы.

### 2.4. Ключевые требования
- **Аудио-callback:** Никогда не блокируется. `try_push` в ring buffer, при переполнении — дроп старых данных.
- **Производительность:** Отсутствие аллокаций в горячем цикле (предвыделенные буферы).
- **Атомарность настроек:** Worker читает снимок настроек (`Arc<Settings>`) на границе кадра.
- **Разделение потоков:** UI не выполняет тяжелые вычисления (FFT, декодирование).
- **DSD Native/DoP:** Визуализация принудительно отключается, показывается плейсхолдер.

## 3. Режимы визуализации

### 3.1. Список режимов
| ID | Название | Тип | Описание |
|---|---|---|---|
| `off` | Отключено | — | Плейсхолдер (Артист, Альбом, Формат). |
| `oscilloscope` | Осциллограмма | Полнотрековый | Огибающая сигнала (envelope) всего трека. |
| `spectrogram` | Спектрограмма | Полнотрековый | Частота × Время, тепловая карта. |
| `spectrum` | Анализатор спектра | Мгновенный | Столбчатая диаграмма частот в реальном времени. |

### 3.2. Переключение
- Через контекстное меню или кнопку в UI.
- Горячая клавиша `V` (циклически).
- Сохранение последнего выбранного режима в конфиг.

---

## 4. Канальный режим: Стерео / Моно

- **Стерео:** Раздельная отрисовка L и R (две дорожки, два стека спектрограммы или два набора полос).
- **Моно:** Суммирование L+R перед обработкой, одна дорожка/набор.
- Настройка индивидуальна для каждого типа визуализации.

---

## 5. Настройки визуализации

Настройки хранятся в секции `[visualization]` конфига.

### 5.1. Общие параметры (для всех типов)
- `channels`: `mono` | `stereo` (default: `stereo`).
- `bg_color`, `fg_color`: Цвета (hex).
- `sensitivity`: Множитель амплитуды (0.1 – 10.0).

### 5.2. Осциллограмма
- `line_width`: Толщина линии (px).
- `draw_center_line`: Показать ось Y.
- `max_columns`: Детализация (кол-во вертикальных срезов).
- `cache_in_memory`, `cache_on_disk`: Управление кэшем.

### 5.3. Спектрограмма
- `fft_size`: 512 – 8192 (step powers of 2).
- `window_type`: Hann, Hamming, Blackman.
- `freq_scale`: Linear, Log, Mel.
- `gain_db`, `range_db`: Усиление и динамический диапазон.
- `palette`: Magma, Viridis, Plasma, Inferno, Rainbow, Gray.
- `dsd_cic_compensation`: Подъем ВЧ для компенсации фильтра DSD.

### 5.4. Анализатор спектра (Мгновенный)
- `bands`: Кол-во полос (4 – 128).
- `smoothing`: Коэффициент затухания (0.0 – 0.95).
- `peak_hold`: Показывать пиковые значения.
- `peak_decay_ms`: Скорость спада пиков.
- `bar_gap`, `bar_radius`: Стиль отрисовки столбцов.
- `gradient`: Градиентная окраска столбцов.

## 6. Обработка DSD

### 6.1. Режимы работы
| Режим вывода | Визуализация | Примечание |
|---|---|---|
| **DSD → PCM** | ✅ Работает | Визуализация строится по PCM-потоку после конвертации. |
| **Native DSD** | ❌ Отключена | Нет PCM-потока. Показывается плейсхолдер. |
| **DoP** | ❌ Отключена | Нет доступа к чистому PCM. Показывается плейсхолдер. |

### 6.2. Особенности DSD → PCM
- Используется тот же `DsdDecoder`, что и для вывода.
- Возможна задержка построения (прогресс-бар обязателен).
- Рекомендуется включенная компенсация CIC (`dsd_cic_compensation`).

---

## 7. Bit-perfect режим и Громкость

### 7.1. Поведение громкости
- В режиме `bit_perfect = true`:
  - Софтверная регулировка громкости в приложении **отключается**.
  - Слайдер громкости в UI блокируется.
  - Подпись: *"Громкость управляется внешним предусилителем / ОС"*.
  - Mute отключается (или реализуется аппаратно, если возможно, иначе игнорируется).
- **Важно:** Bit-perfect не гарантирует эксклюзивный доступ к ЦАП (зависит от ОС/драйвера), но гарантирует отсутствие цифровой обработки внутри приложения.

### 7.2. Влияние на визуализацию
- **PCM Bit-perfect:** Визуализация работает корректно (через tap до вывода).
- **DSD Bit-perfect (Native/DoP):** Визуализация отключена (см. п. 6).
- **DSD → PCM:** Не является строго bit-perfect для исходного DSD потока, визуализация работает.

---

## 8. Настройки DSD → PCM

Секция `[dsd]` в конфиге и отдельная вкладка в UI.

### 8.1. Параметры
- `enabled`: Включить конвертацию (иначе ошибка или native, если поддерживается).
- `target_bit_depth`: 16, 24, 32 (int/float).
- `target_sample_rate`: Auto, 44.1k, 48k, 88.2k, 96k, 176.4k, 192k.
- `resampler`:
  - Этап 1: `linear`, `cubic`, `sinc_fast`, `sinc_medium` (чистый Rust).
  - Этап 2 (опц.): `soxr_hq`, `soxr_vhq` (требуется libsoxr).
- `filter_order`: Порядок CIC фильтра (2–8).
- `dither`: Включить дизеринг (TPDF, Triangular).
- `lowpass_cutoff_hz`: Частота среза ФНЧ.

### 8.2. Предупреждения
- При включении Bit-perfect и выборе режима DSD→PCM показывать предупреждение о нарушении битовой точности исходного DSD потока.

## 9. Управление кэшем

Новый раздел в настройках **"Хранилище"**.

### 9.1. Параметры
- `cache_max_size_mb`: Максимальный размер кэша на диске (default: 500 МБ).
- `cache_ttl_days`: Срок жизни кэша (опционально).

### 9.2. Действия
- Кнопка **"Очистить кэш визуализации"**.
- Кнопка **"Очистить кэш обложек"**.
- Кнопка **"Очистить всё"**.
- Отображение текущего размера занятого места.
- Автоматическая очистка старых файлов (LRU) при превышении лимита.

## 10. UI Компоненты (Slint)

### 10.1. Visualizer Component
- Расположение: Центральная область главного окна (под шапкой или вместо обложки).
- Свойства:
  - `mode`: Enum (Off, Osc, Spec, Spectrum).
  - `data_image`: `Image` (для полнотрековых).
  - `data_bars`: `Model<float>` (для спектра).
  - `cursor_position`: Float (0.0–1.0) для вертикальной линии.
  - `is_building`: Bool (показывать индикатор прогресса).

### 10.2. Placeholder Component
- Выделен в отдельный файл `visualizer_placeholder.slint`.
- Отображает: Артист, Альбом, Формат.
- Специфические сообщения: "Визуализация недоступна в режиме Native DSD".

### 10.3. Настройки
- Вкладка "Визуализация": Выбор режима, ползунки настроек, сброс.
- Вкладка "DSD": Настройки конвертера.
- Вкладка "Хранилище": Управление кэшем.

---

## 11. Производительность и Требования

### 11.1. Бюджеты
- **Построение (Full-track):** ≤ 3 сек для 5-мин трека (PCM), ≤ 30 сек (DSD512).
- **FPS (Spectrum):** ≥ 30 FPS стабильно.
- **CPU (LiveWorker):** ≤ 5% одного ядра.
- **Память:** ≤ 64 МБ суммарно на кэш в RAM.

### 11.2. Оптимизации
- Использование `rustfft` с переиспользуемым планом.
- `rtrb` (real-time ring buffer) для передачи аудио.
- Векторизация операций над сэмплами.
- Debounce перестройки буферов при изменении размера окна.

## 12. Этапы реализации

1. **Каркас (Foundation)**
   - Модуль `audio::visualizer`.
   - Структуры настроек и сериализация (TOML).
   - UI компонент-плейсхолдер (уже есть, доработать интеграцию).
   - Tap в audio callback (условный, пока пустой).

2. **Мгновенный спектр (Live Spectrum)**
   - `LiveWorker` + `rustfft`.
   - Алгоритм сглаживания (Decay/Peak Hold).
   - Отрисовка столбцов в Slint.
   - Настройки (полосы, цвета).

3. **Полнотрековая осциллограмма**
   - `FullTrackWorker` (чтение файла, min/max децимация).
   - Генерация изображения.
   - Синхронизация курсора с прогрессом плеера.
   - Кэширование в RAM.

4. **Спектрограмма и DSD**
   - FFT по файлу, тепловая карта.
   - Поддержка `DsdDecoder`.
   - Настройки DSD конвертации (базовые ресемплеры).

5. **Полировка и Кэш**
   - Кэширование на диск с лимитом размера.
   - UI управления кэшем.
   - Оптимизация производительности.
   - Тесты и документация.

---

## 13. Критерии приемки

- [ ] Переключение режимов работает без перезапуска трека.
- [ ] Спектр реагирует на музыку плавно (без рывков), FPS ≥ 30.
- [ ] Осциллограмма строится за разумное время, курсор движется синхронно с прогресс-баром.
- [ ] В режиме Native DSD показывается плейсхолдер.
- [ ] В режиме Bit-perfect слайдер громкости заблокирован с пояснением.
- [ ] Настройки сохраняются и применяются после перезапуска.
- [ ] Очистка кэша работает, лимит размера соблюдается.
- [ ] Отсутствие паник и блокировок в аудио-потоке.
