# ROADMAP — аудиофильский плеер (Rust)

## 1. Цель создания приложения

Построить **нативный аудиофильский музыкальный плеер** с максимальной точностью звука
и высокой надёжностью, ориентированный на Linux и независимый от конкретного окружения
рабочего стола (KDE/GNOME/XFCE/прочие). Плеер является переосмыслением и переписью
Python-прототипа на Rust: однонативный бинарник, без рантайма, с собственным
декодированием (Symphonia + кастомный DSD-декодер) и выводом (cpal с bit-perfect
при совпадении частот).

**Цели:**
- Максимальное качество звука: собственное декодирование, native-rate / bit-perfect
  вывод, DSD (DSF/DFF) с кастомным CIC-декодером.
- Надёжность: автосохранение сессии, атомарная запись, защита от фризов GUI через
  фоновые потоки, автотесты.
- Независимость от DE: собственный трей (StatusNotifierItem/ksni), отсутствие привязки
  к Qt/GTK, работа через X11/XWayland на всех DE.
- Удобство: полный транспорт (repeat/shuffle), настраиваемый плейлист, визуализация,
  обложки, системный трей.
- Архитектура с расчётом на будущий порт на другие ОС (Linux в приоритете; прочие —
  обсуждается позднее).

## 2. Основные требования к приложению

### 2.1 Функциональные требования
1. **Форматы**: FLAC, WAV, AIFF/AIF, ALAC, M4A/MP4/AAC, MP3, OGG/Opus, DSF/DFF
   (DSD64–1024). (Уже частично есть.)
2. **Транспорт**: Play/Pause, Stop, Prev/Next, Seek слайдером и клавишами, громкость,
   mute.
3. **Repeat (OFF/ALL/ONE) и Shuffle** — требуются (сейчас отсутствуют).
4. **Выбор аудиоустройства** — требуется (сейчас только системный дефолт).
5. **Плейлист**:
   - 10 колонок: `# Title Artist Album Year Format Bitrate Bit Depth Sample Rate Duration`.
   - Сортировка по колонкам.
   - Настройка видимых колонок и их порядка.
   - Сохранение размеров колонок.
6. **Визуализация** (mono/stereo): waveform, spectrogram, frequency bars; отдельные
   настройки на каждый режим; **отключена для DSD**.
7. **Обложки альбомов**: из файла → из папки → из интернета (приоритет настраиваемый),
   кэш, настраиваемый список имён для поиска в папке. *(Отложено — требует новых
   зависимостей.)*
8. **Расположение UI** повторить с Python-версии (обложка + панель трека + транспорт +
   визуализация + громкость + seek + статусбар).
9. **Панель трека (13 полей)**: Artist, Track #, Title, Duration, Year, Album, Disc,
   Genre, Format, Bitrate, Bit Depth, Sample Rate, Channels.
10. **Bit depth для DSD** отображать как `dsd64/128/256/512`.
11. **Настройки**: Внешний вид (темы тёмная/светлая), колонки плейлиста, обложки
    (приоритет, список имён).
12. **Автосохранение** всего: настройки, плейлист (в т.ч. размеры колонок), режим
    прослушивания, громкость. Плейлист — в отдельный файл.

### 2.2 Нефункциональные требования
- **Производительность**: декодирование/визуализация в фоновых потоках, GUI не
  фризится; release `opt-level=3`, LTO.
- **Надёжность**: атомарная запись файлов, автосохранение по таймеру, корректная
  остановка потоков, автотесты.
- **Кроссплатформенность (в будущем)**: изоляция аудио- и UI-слоёв; Linux — сейчас,
  прочие ОС — позже.
- **Независимость от DE**: без Qt/GTK, трей через SNI (ksni).
